# 🚀 Руководство по переносу ботов на отдельный сервер (VPS)

Это руководство поможет вам перенести текущего бота **Price Tracker** и всех будущих ботов на отдельный виртуальный сервер (VPS), чтобы они работали круглосуточно (24/7) без необходимости держать включённым свой ПК.

---

## 1. Выбор сервера (VPS)

Для работы Telegram-ботов на Python не нужны мощные и дорогие серверы. Достаточно самого простого тарифа:
* **Характеристики:** 1–2 vCPU, 1–2 GB RAM, 10–20 GB SSD.
* **ОС:** `Ubuntu 22.04 LTS` или `Ubuntu 24.04 LTS`.
* **Рекомендуемые провайдеры:**
  * **Hetzner Cloud** (тариф CX22 — около 3.5–4 €/мес). *Рекомендуется для Финляндии: у Hetzner есть дата-центр прямо в Хельсинки (Helsinki), пинг до магазинов Tokmanni, Kärkkäinen и Hinta.fi составляет 1–2 мс!*
  * **TimeWeb Cloud** (~250–350 руб/мес) — удобен, если оплата российскими картами.
  * **DigitalOcean / Vultr / Linode** (~4–5 $/мес).

---

## 2. Подключение к серверу

После покупки сервера вам на почту придут:
* **IP-адрес** сервера (например: `195.201.55.10`)
* **Логин:** `root`
* **Пароль** или SSH-ключ

На вашем ПК откройте PowerShell или Командную строку (CMD) и введите:
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```
*(При первом подключении введите `yes` и затем вставьте пароль).*

---

## 3. Установка Docker на сервере

На сервере выполните команду (установит Docker и Docker Compose автоматически за 1 минуту):
```bash
curl -fsSL https://get.docker.com | sh
```

---

## 4. Перенос файлов бота на сервер

Создайте на сервере общую папку для всех ваших ботов:
```bash
mkdir -p /opt/bots/price_tracker_bot
```

### Способ A: Через SFTP (самый простой — мышкой)
1. Скачайте бесплатную программу **WinSCP** или **FileZilla** на свой ПК.
2. Подключитесь по SFTP к вашему серверу (протокол SFTP, хост: IP сервера, логин: `root`, ваш пароль).
3. Перетащите файлы из папки `C:\Users\bratt\Desktop\price_tracker_bot` в папку `/opt/bots/price_tracker_bot` на сервере.
*(Папку `.venv` копировать не нужно — Docker сам всё установит внутри контейнера).*

### Способ B: Через Git (если проект на GitHub)
```bash
cd /opt/bots
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> price_tracker_bot
cd price_tracker_bot
```

---

## 5. Запуск бота в Docker

1. Перейдите в папку бота на сервере:
   ```bash
   cd /opt/bots/price_tracker_bot
   ```
2. Убедитесь, что в файле `.env` указан правильный `BOT_TOKEN`:
   ```bash
   nano .env
   # (Для сохранения: Ctrl+O -> Enter -> Ctrl+X)
   ```
3. Запустите бота одной командой:
   ```bash
   docker compose up -d --build
   ```

**Готово!** Бот собран в изолированный контейнер и работает 24/7 в фоне:
* Если сервер перезагрузится (например, при обновлении хостинга), Docker **автоматически запустит бота** снова (`restart: always`).
* База данных (`bot.db`) хранится в подпапке `./data` на сервере и не сбросится при перезапусках.

---

## 6. Как запускать всех последующих ботов на этом же сервере

На сервере с 1-2 ГБ оперативной памяти можно одновременно держать **15–25 Telegram-ботов** (каждый потребляет всего ~40-60 МБ RAM).

Архитектура очень простая: **каждый бот в своей папке**:
```text
/opt/bots/
├── price_tracker_bot/      <-- первый бот
│   ├── Dockerfile
│   ├── docker-compose.yml
│   └── .env
├── bot_two/                <-- ваш второй бот (например, crypto-alert)
│   ├── Dockerfile
│   ├── docker-compose.yml
│   └── .env
└── bot_three/              <-- ваш третий бот
    ├── Dockerfile
    ├── docker-compose.yml
    └── .env
```

Для каждого нового бота:
1. Создайте папку: `mkdir -p /opt/bots/bot_two`
2. Загрузите туда его файлы.
3. В `docker-compose.yml` нового бота укажите уникальное имя контейнера (например: `container_name: bot-two`).
4. Запустите:
   ```bash
   cd /opt/bots/bot_two
   docker compose up -d --build
   ```

Все боты будут работать независимо, не конфликтуя друг с другом по библиотекам или версиям Python.

---

## 7. Шпаргалка по управлению ботами

* **Посмотреть всех запущенных ботов:**
  ```bash
  docker ps
  ```
* **Посмотреть живые логи бота в реальном времени:**
  ```bash
  cd /opt/bots/price_tracker_bot
  docker compose logs -f
  ```
* **Перезапустить бота:**
  ```bash
  docker compose restart
  ```
* **Остановить бота:**
  ```bash
  docker compose down
  ```
* **Обновить бота после изменения кода:**
  ```bash
  docker compose up -d --build
  ```
* **Проверить нагрузку на процессор и память всех ботов:**
  ```bash
  docker stats
  ```
