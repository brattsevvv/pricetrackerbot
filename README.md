# 🛒 Telegram Bot: Поиск и отслеживание лучших цен (Финляндия + Европа)

Телеграм-бот, который ищет самое выгодное предложение на товары, спортпит и электронику с учетом геолокации и доставки (включая финские и европейские магазины), а затем раз в день автоматически проверяет цены и уведомляет о появлении более выгодных предложений.

---

## 🌟 Возможности

1. **Мульти-магазинный поиск цен с учетом доставки:**
   - **Спортивное питание и здоровье**: *Kärkkäinen*, *Fitnesstukku.fi*, *Verkkokauppa.com*, а также быстрые ссылки на *Prisma (S-Kaupat)* и *Tokmanni*.
   - **Электроника и товары для дома**: *Verkkokauppa, Gigantti, Power, DNA, Elisa, Telia, Veikon Kone, Multitronic, Datatronic, Tietokonekauppa, Jimm's, Kärkkäinen* и европейские/скандинавские магазины (*MaxGaming, Scandinavian Photo, Proshop*).
   - Расчет **итоговой стоимости**: `Цена товара + Доставка = Итого`. Если доставка платная (или бесплатная от порога суммы), бот сразу учитывает это в ранжировании.
2. **Отслеживание цен в 1 клик:**
   - Под каждым найденным товаром есть кнопка `[🔔 Отслеживать лучшую цену]`.
3. **Ежедневный фоновый мониторинг (APScheduler):**
   - Бот раз в сутки проверяет актуальные цены на все сохраненные товары (в Kärkkäinen, Fitnesstukku, Verkkokauppa и др.).
   - Если найдена цена ниже сохраненной, бот присылает сообщение:
     > 🎉 **Цена снизилась!**
     > Старая цена: ~14.80 €~ ➡️ **Новая цена: 11.89 €**
     > Магазин: *Kärkkäinen*
     > `[🛒 Купить в Kärkkäinen]`
4. **Удобный личный кабинет:**
   - Просмотр всех отслеживаемых товаров (`/tracked` или кнопка `📋 Мои товары`).
   - Кнопка ручной проверки цен прямо сейчас (`🔄 Проверить цены сейчас`).
   - Удаление товаров из отслеживания в 1 клик.
5. **Быстрые кнопки сравнения:**
   - В каждой карточке доступны кнопки для моментального перехода в поиск *Prisma (S-Kaupat)* и *Tokmanni*.
6. **Умная обработка запросов (кириллица и опечатки раскладки):**
   - **Автоисправление раскладки (QWERTY ⇄ ЙЦУКЕН)**: понимает запросы вроде `rhtfnby` (креатин), `скуфешту` (creatine), `ghjntby` (протеин), `дщпшеуср` (logitech).
   - **Перевод с русского на финский/международный**: понимает `креатин` ➡️ `kreatiini`, `протеин` ➡️ `proteiini`, `сывороточный` ➡️ `whey`, `наушники` ➡️ `kuulokkeet`, `видеокарта` ➡️ `näytönohjain` и др.

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям.
3. Скопируйте полученный токен (вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### 2. Настройка файла `.env`
Откройте файл `.env` в папке проекта и вставьте ваш токен:
```ini
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
DB_URL=sqlite+aiosqlite:///bot.db
CHECK_HOUR_UTC=7
```

### 3. Запуск бота
Просто дважды кликните по файлу **`start.bat`** (или выполните команду в консоли):
```powershell
.venv\Scripts\python.exe main.py
```
