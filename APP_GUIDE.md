# 📱 Инструкция: Price Tracker для Компьютера и Android

Это руководство описывает работу с кроссплатформенным приложением **Price Tracker Finland**:
1. **На компьютере:** работает прямо в браузере как десктопное приложение.
2. **На телефоне Android:** устанавливается как автономное приложение (PWA) с иконкой на главном экране.
3. **Без необходимости платить за сервер (0 €/мес):** можно запускать прямо с ПК или на бесплатном облачном тарифе.
4. **Мгновенные обновления:** при любых доработках функционала приложение на телефоне обновляется **автоматически** без необходимости вручную переустанавливать APK-файлы!

---

## 1. Запуск на компьютере (ПК)

На рабочем столе появился файл:
👉 **`Start_Price_Tracker_App.bat`** (или `start_web_app.bat` в папке бота).

1. Дважды кликните по файлу.
2. Запустится быстрый локальный сервер и в вашем браузере автоматически откроется страница:
   **`http://localhost:8080`**

### Что умеет приложение на ПК:
* 🔍 **Умный поиск с автоисправлением раскладки и опечаток:** вводите `протеин`, `соевый протеин`, `rhtfnby`, `кофемашина`, `мокамастер`.
* 🥇 **Сравнение цен с доставкой:** сразу показывает самый дешевый вариант с бейджем «🔥 Лучшая цена».
* 🏪 **Фильтры по магазинам:** Tokmanni, Kärkkäinen, Fitnesstukku, Hinta.fi.
* 🛒 **Прямой переход в Prisma (S-Kaupat) и Tokmanni:** быстрые кнопки в один клик.
* ⭐ **Отслеживание и избранное:** кнопка «⭐» сохраняет товар, во вкладке «Отслеживаемые» можно нажать «🔄 Проверить цены сейчас» для проверки снижения цен.

---

## 2. Использование на телефоне (Android) через домашний Wi-Fi

Если ваш компьютер включён, телефон в той же сети Wi-Fi может открыть приложение напрямую:

1. При запуске `Start_Price_Tracker_App.bat` в черном окне консоли будет написан локальный адрес, например:
   ```text
   📱 На телефоне (в сети Wi-Fi): http://192.168.1.120:8080
   ```
2. Откройте браузер **Google Chrome** на телефоне и введите этот адрес.
3. Внизу появится подсказка: **«Добавить Price Tracker на главный экран»** (или нажмите 3 точки в правом верхнем углу Chrome ➡️ **«Установить приложение»** / **«Добавить на главный экран»**).
4. На экране вашего Android-смартфона появится **полноценная иконка приложения**!
5. При открытии с главного экрана оно работает на весь экран без адресной строки браузера — как обычное мобильное приложение.

## 3. Как сделать доступ 24/7 с телефона (без включенного ПК и без платы за сервер)

Чтобы приложение открывалось на телефоне всегда (на улице, в спортзале, через мобильный 4G/5G), не держа компьютер включённым, идеальное решение — **бесплатный облачный хостинг** (0 €/мес):

### Бесплатный запуск на [Render.com](https://render.com) (100% Free):
1. Зарегистрируйтесь бесплатно на [Render.com](https://render.com) (через Google или GitHub).
2. Загрузите файлы проекта в бесплатный репозиторий на [GitHub.com](https://github.com) (или перетащите файлы).
3. На Render нажмите **«New +» ➡️ «Web Service»** и выберите ваш репозиторий.
4. Выберите **Free Plan** (0$ в месяц).
5. Нажмите **«Deploy»**.

Render выдаст вам постоянную защищенную ссылку:
👉 **`https://price-tracker-fi.onrender.com`**

* Откройте эту ссылку на телефоне в Chrome.
* Нажмите **«Установить приложение»**.
* Теперь приложение доступно 24/7 с любого устройства в любой точке мира!

## 4. Как быстро обновлять приложение на телефоне

Это ключевое преимущество созданной PWA-архитектуры:
* В классических APK-файлах при каждом изменении кода (добавили магазин, изменили фильтр) нужно заново собирать APK, перекидывать по кабелю на телефон и вручную переустанавливать.
* В **Price Tracker PWA**:
  1. Вы меняете код на компьютере или в репозитории.
  2. Вы просто открываете приложение на телефоне — и Service Worker **автоматически на лету подтягивает обновленный код**!
  3. Никаких переустановок, скачиваний заново и возни с файлами.

---

## 5. Если вам обязательно нужен отдельный файл `.apk`

Если вам нужен именно установочный файл `.apk` для отправки друзьям или установки в систему:
1. Официальный сервис от Microsoft: **[PWABuilder.com](https://www.pwabuilder.com/)**.
2. Вставьте URL вашего работающего приложения (например, адрес Render или ngrok).
3. Нажмите кнопку **«Package for Android»** ➡️ **«Generate APK»**.
4. Сервис сгенерирует готовый файл `price-tracker.apk`, который можно установить на любой Android-телефон.
